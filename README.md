uv was used to handle this project's management.

How to run this project (project root dir):
- git clone https://github.com/fran-felix/histogram-retriever.git
- uv add -r requirements.txt
- uv run src/histogram_retriever/main.py

Tools used:
- PIL library for image loading
- Numpy library for array handling
- uv to handle dependencies and set up the project environment
- VSCode WSL as a workspace

AI tools used:
- GitHub Copilot was used for error explanations and minor code optimizations/corrections. The majority of the code
and all of the logic and planning was done by the author of this project.
